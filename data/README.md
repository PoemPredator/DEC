# 气动数据

本目录用于放置仿真所需的气动数据表，文件已被 `.gitignore` 忽略，不纳入版本管理。

## 文件约定

- 默认文件名：`气动数据.xlsx`
- 默认工作表：`Sheet1`
- 只使用**单一**数据表（不再按马赫数拆分高/低马赫两张表）

若文件名或位置不同，请通过环境变量指定：

```matlab
setenv('AERO_DATA_FILE', 'D:\aero_data\气动数据.xlsx')
```

或在工况中覆盖：

```matlab
bias.aero = struct('data_file', 'D:\aero_data\气动数据.xlsx');
```

## 列名要求

工作表第一行必须包含以下列名（严格一致，大小写敏感）：

| 列名 | 含义 | 单位 |
| --- | --- | --- |
| `dn` | 方向舵偏角 | deg |
| `d2` | 左升降舵偏角 | deg |
| `d4` | 右升降舵偏角 | deg |
| `alpha` | 攻角 | deg |
| `beta` | 侧滑角 | deg |
| `Cx` | 轴向力系数 | - |
| `Cy` | 法向力系数 | - |
| `Cz` | 侧向力系数 | - |
| `Cmx` | 滚转力矩系数 | - |
| `Cmy` | 偏航力矩系数 | - |
| `Cmz` | 俯仰力矩系数 | - |

数据需覆盖 `alpha`、`beta` 与三个舵偏的完整网格：插值器会分别以
“零舵偏基础项 + 各舵面增量项”的方式构建（详见 `src/core/AeroInterpolant.m`）。
