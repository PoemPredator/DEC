# 程序说明与新旧对照

本文件记录工程化整理的内容：目录职责、主脚本行为、核心研究点、新旧文件
对照，以及重构过程中做出的接口调整。

## 1. 目录职责

| 目录 | 职责 |
| --- | --- |
| `config/` | 参数配置：模型参数、控制器参数、气动数据文件位置 |
| `src/core/` | 仿真内核：闭环仿真入口、动力学、控制律、气动插值 |
| `src/experiments/` | 批量仿真编排（并行、随机样本池、工况构造） |
| `src/analysis/` | 与仿真解耦的分析算法：配平、包络统计、系数优化 |
| `src/plotting/` | 可复用的绘图工具 |
| `src/utils/` | 路径、单位转换、代价函数、图片保存等通用工具 |
| `scripts/` | 可直接运行的主脚本（只负责配置与串联） |
| `data/` | 气动数据与本地参数（不纳入版本管理） |
| `results/` | 全部运行输出（不纳入版本管理） |

依赖方向单向：`scripts → experiments/analysis → core → config`。

## 2. 主脚本说明

### 2.1 `main_single_run.m`

一次名义工况仿真并绘制 9 条时域曲线（3 个气流角、3 个角速度、3 个舵偏）。

- 可调：`cfg` 中的初值、时长、速度剖面、补偿系数、拉偏、外扰；
- 结果缓存：`cfg.load_results = true` 时读取 `results/single_results.mat`。

### 2.2 `main_controller_compare.m`

- `mode = 'nominal'`：PD 与 ADRC 单次对比，无拉偏无外扰；额外输出
  Cmz 与 d2 舵效的时变曲线；
- `mode = 'aero_dispersion'`：50 组气动拉偏样本，绘制 PD/ADRC 包络带。

### 2.3 `main_monte_carlo.m`（核心研究脚本）

- `mode = 'envelope'`：若干候选补偿系数在 Bang-Bang 外扰下的响应包络与最坏 ISE；
- `mode = 'coeff_opt'`：在补偿系数网格上求最坏情形最优系数。

两模式共享同一套随机扰动样本（切换时刻、初始符号、气动拉偏），保证不同
补偿系数之间可比。算法分别在 `src/analysis/envelope_report.m` 与
`src/analysis/coeff_worst_case.m`。

### 2.4 `main_initial_sweep.m`

扫描“初始攻角 × 初始俯仰角速度”网格，统计收敛工况并绘制响应曲线与收敛性
散点图。边界工况强制判为不可控。单工况由 `run_initial_case.m` 执行，便于并行。

### 2.5 `main_trim.m`

在固定速度下扫描攻角，用 `fmincon` 求配平舵偏，输出配平舵偏、角加速度残差、
竖直力残差、竖直加速度与角度导数 5 张图。

- `cfg.trim_mode = 1`：力矩 + 竖直力联合最小二乘（原始默认）；
- `cfg.trim_mode = 2`：纯力矩配平。

### 2.6 `main_aero_plot.m`

读取单一气动数据表，绘制法向力系数、俯仰/滚转力矩系数随攻角与舵偏的变化，
以及标称速度下的有量纲俯仰力矩和俯仰舵效。由原 `aeroplot0629.m` 改写：
不再区分马赫数，也不做两表对比。

### 2.7 已删除的脚本

| 原脚本 | 说明 |
| --- | --- |
| `main/compute_margins_alpha_channel.m` | 按要求删除攻角通道相位/幅值裕度计算及其辅助函数 |

## 3. 核心贡献：补偿系数 `coeff` 的最坏情形优化

这是本工程的研究重点，也是评奖/汇报时应重点展示的部分。

### 3.1 设计变量与问题

控制律中的 ESO 补偿项为 `-coeff * hat_D2`，`coeff` 直接决定补偿强度：

- `coeff = 0`：关闭 ESO 补偿，退化为 PD 控制；
- `coeff = 1`：完全补偿内环集总扰动，即标准 ADRC；
- 其他取值（含负值）：欠补偿 / 过补偿，用于考察补偿强度与鲁棒性的关系。

优化问题：在外部扰动（及可选气动拉偏）不确定下，寻找使**最坏跟踪误差**最小的
`coeff`。

### 3.2 指标与算法

指标为过程积分平方误差 ISE：

```
J(coeff) = max_k ∫ z_k(t)' Q z_k(t) dt
z = [alpha - alpha_cmd; beta - beta_cmd; wx; wy; wz]
```

其中 `k` 为同一组 Bang-Bang 扰动样本的编号，`Q` 由气流角/角速度归一化尺度
构成（见 `src/utils/compute_tracking_cost.m`）。

求解步骤：

1. `run_batch_simulations` 生成共享扰动样本（切换时刻、初始符号、气动拉偏），
   对整张系数网格批量仿真，保证不同 `coeff` 面对完全相同的样本；
2. `coeff_worst_case` 逐系数取最坏样本的 ISE，得到 `J(coeff)` 曲线；
3. 取 `min J(coeff)` 对应系数为最优 `coeff*`，并输出最坏响应与最坏扰动曲线。

### 3.3 输出与复现

```matlab
cd scripts
% 打开 main_monte_carlo.m，将 mode 设为 'coeff_opt'
main_monte_carlo
```

输出目录 `results/coeff_optimization/`：

- `10_最坏代价随补偿系数变化.*`：`J(coeff)` 曲线与最优点；
- `01`–`09`：各候选系数的最坏响应对比；
- `11_最优系数最坏扰动_*`：最优系数对应的最坏扰动；
- `coeff_optimization_worstcase_results.mat`：`J_all`、`worst_J`、`optimal_coeff` 等。

`envelope` 模式则给出候选系数在同一扰动样本下的响应包络对比，用于直观展示
补偿强度对响应带宽与收敛性的影响。

## 5. 重构带来的接口变化

### 5.1 模型参数外置与保密

- 原 `calcu0621.m` 内嵌的 `g / m / I / xz / L / S / rho` 全部移入
  `config/model_params.m`；
- 该文件只保留字段定义与加载逻辑，具体数值由本地参数文件提供，
  未纳入版本管理；缺失时退化为中性演示值并提示；
- 气动数据文件路径不再写死为个人电脑的绝对路径，由 `config/aero_config.m`
  统一解析，默认 `<工程根>/data/气动数据.xlsx`。

### 5.2 气动数据统一为单表

- 原程序读取 `Ma4.xlsx` 与 `Ma7.xlsx` 并按马赫数线性插值；现在只使用一张
  `气动数据.xlsx`，仿真中不再做马赫插值；
- `p.aero_model` 现在是 `AeroInterpolant` 对象，调用方式为
  `p.aero_model.evaluate(alpha_deg, beta_deg, dn, d2, d4)`。

### 5.3 去除全局变量 `ctrl_log`

原实现用 `global ctrl_log` 记录舵偏，再在仿真后插值。现在
`attitude_dynamics` 增加第三个输出 `u_deg`，`simulate_attitude` 在积分结束后
对每个输出时刻重新求值控制律即可得到 `u`：

- 结果等价（控制律是状态与时间的确定性函数）；
- 不再污染工作区全局变量，并行运行时也不会互相干扰。

### 5.4 仿真入口签名

```matlab
% 旧接口
[t, x, u, p] = calcu0621(bias);

% 新接口
[t, x, u, p] = simulate_attitude(bias);
```

`bias` 字段保持不变（`tend, alpha0, beta0, gammas0, wx0, wy0, wz0, V,
coeff, hl, disturbance`），并可选增加 `model / controller / aero` 覆盖默认配置。

### 5.5 输出位置

原脚本把图片与 MAT 写在当前文件夹；现在统一写入
`<工程根>/results/<子目录>/`，脚本内通过 `output_dir()` 获取路径。

## 6. 未改动的部分（物理与控制）

为避免“整理结构”意外改变仿真结论，以下内容与原始程序保持一致：

- 姿态运动学与动力学方程、坐标系定义；
- PD + ESO ADRC 控制律、ESO 增益与限幅逻辑；
- 配平残差定义（含 `p.theta` 的历史取值与量纲不一致问题）；
- 气动插值的“基础项 + 各舵面增量项”构造方式，以及宏观割线法舵效导数；
- 随机数种子、样本数量与扰动生成方式（均在脚本配置中显式给出）。
